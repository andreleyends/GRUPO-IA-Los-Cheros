## Daily 23/10/2026

### Progreso

- 3.1: 4.000 imagenes, 28.565 instancias y 0 errores de color.
- 3.3: train 3.204, val 398, test 398 imagenes.
- 3.2: 24.861 positivos y 49.462 negativos.
- 4.1: CNN con accuracy top-1 0,624 y top-3 0,806.
- 4.2: compatibilidad con AUC 0,866 y F1 0,705.
- 4.3: taste con NDCG@10 0,964 y reglas con 0 % de violacion top-10.
- 5.1 y 5.2: consolidado y ablacion generados.
- Documentos Word y README generados.

### Decisiones

- Aceptar el resultado de 4.1 pese al macro F1 bajo, explicado por clases raras.
- Reportar el AUC de taste como consistencia sintetica, no validacion real.
- Mantener el punto de operacion con reglas: poca perdida de NDCG y eliminacion
  de violaciones en el top-10.

### Bloqueos y resoluciones

- `ValueError: array is read-only` en 3.3: se corrigio con `.copy()`.
- Salida de 4.1 truncada: se conservo la salida completa en el archivo de log y
  se verificaron las metricas finales.
- Tiempo ajustado: se priorizaron los entregables y se documento la deuda del
  dataset completo.
